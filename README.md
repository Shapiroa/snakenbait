# 🐍 Snake & Bait Game

A fully customizable, modern take on the classic Snake game — upload your own snake and bait images and play on a beautiful, responsive, cloud-filled board!

## 🚀 Features

- **Upload Your Own Snake & Bait:** Personalize your game by uploading any images for the snake and bait.
- **Classic Snake Mechanics:** The snake grows each time it eats the bait, and the game ends on collision with itself or the wall.
- **Responsive Design:** The game board automatically scales to 90% of your screen on desktop and mobile.
- **Beautiful Background:** Play against a retro-style sky with pixel clouds.
- **Keyboard & Touch Controls:** Use arrow keys or swipe on mobile to control the snake.
- **Score Tracking:** See your score and restart instantly.
